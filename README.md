# 📖 Quran Web Application

A full-stack Quran web application built to provide a smooth and accessible reading experience of the Holy Quran. This project includes both a frontend and backend, deployed separately for scalability and performance.

---

## 🚀 Live Demo

* 🌐 Frontend: https://quran-web-application-frontend.vercel.app/
* ⚙️ Backend API: https://quran-web-application-backend.vercel.app/

---

## 🛠️ Tech Stack

### Frontend

* Next.js
* Tailwind CSS
  

### Backend

* Node.js
* Express.js

---

## 📂 Project Structure

```
quran-web-application/
│
├── frontend/   # Client-side application
└── backend/    # Server-side API
```

---

## ⚙️ Installation & Setup



### 2️⃣ Run Backend

```bash
cd backend
npm install
node server.js
```

Backend will run locally (default: http://localhost:5000 or your configured port).

---

### 3️⃣ Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend will run at:

```
http://localhost:3000
```
